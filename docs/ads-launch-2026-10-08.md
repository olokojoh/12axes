## 对原建议的判断

可以低成本、小范围试验，暂不适合按点击量扩预算。原文经济数据按用户提供的事实采用，但收入保本 CPC 不等于利润保本 CPC，还要扣支付手续费、退款、税费和边际服务成本。US$4.99 是售价，不能直接当作可接受 CPA。

美国自然排名已经不错，品牌相关词广告可能替代原本免费的点击。Ads 归因购买不能单独证明新增销量，应同时看美国自然点击、总订单和净贡献。短期小样本只能提供方向，不能证明因果。

US$0.04 是保守的试验上限，不保证盈利。若没有展示，不自动加价或扩大匹配。智能出价不机械套用“全站累计 50 单”，需要可用、相关的广告转化数据和合理预算。

## 一次性预算策略

本账号的搜索系列创建界面确实提供“广告系列总预算”，本轮已实际创建成功。选择 US$100、七天、品牌相关完全匹配词和尽可能争取更多点击次数；CPC 上限仍为 US$0.04。不扩展到品类词、展示、YouTube 或 Performance Max。

总预算限制的是本系列广告费用，不是银行卡全部扣款：税费、历史欠费和其他系列费用不包含在这 US$100 内。总预算模式没有每日硬上限，系统可能集中花费；低 CPC 出价也可能让预算花不出去。US$30 仅为提前复盘点，未配置自动暂停规则，不能把它当作第二个硬上限。

这次实验不自动充值、不增加总额、不延长周期；无流量也不默认提高 CPC。预算不是必须花完的目标。结束后按实际广告点击、真实购买、退款和净贡献判断，同时观察是否替代美国自然搜索流量。

“预付”与“总预算”是两件事。自动付款账号即使提前付款，也不能假设余额归零就停止投放；手动付款是否可用取决于账号和地区。本轮没有修改付款方式或充值，使用系列总预算控制实验费用。

原文的“每次加预算不超过 20%、间隔 3–5 天”可作为经验纪律，但不是平台保证，本轮固定总预算实验不需要加预算。7 天小样本可能不足以判定盈利能力，更不能因偶然一单就扩量。

## 按钮操作手册

### 重新创建一次性预算系列

1. 左侧“创建” → “广告系列” → “在没有目标指导的情况下制作广告系列” → “搜索”。
2. 选择本项目的“购买”转化目标，避免使用共享账号其他站点的目标；填写系列名称。
3. “出价” → 目标选“点击次数” → 勾选“设置每次点击费用的出价上限” → 输入 `0.04` → “下一步”。
4. “广告系列设置” → 取消搜索合作伙伴与展示网络；地理位置只留美国；“地理位置选项”选“所在地”；语言只留英语。网址后缀填写上表内容。
5. “AI Max”保持关闭 → “下一步”。
6. “关键字和广告” → 粘贴上文五个带方括号的词；填写首页 URL、七个标题、两条描述及三个站内链接 → 点击页面“下一步”。
7. “预算” → 选择“广告系列总预算” → 填写 `100.00` → 设置开始、结束日期，保留七天 → “下一步”。不要选“平均每日预算”。
8. “检查” → 确认预算显示总计、美国、英语、仅 Google 搜索、正确广告和关键词 → 等待保存完成 → “发布广告系列”。
9. 若还未完成购买验收，先设未来开始日期；发布后顶部“更改状态” → “已暂停”，刷新并在“广告系列设置”确认状态。

本轮遇到草稿“未能保存更改”。刷新、确认内容确实保留后再次发布成功，并在正式设置中回读确认 US$0.04 上限、专属 purchase 目标和 UTM 后缀。填写完广告应使用页面“下一步”推进，不能只看编辑器预览或“完成”就认定已保存。平台界面提示预算类型在广告系列开始投放后不能更改；总预算金额本身可调整，但本次不增加。

### 验证真实购买

1. Stripe 若出现登录页，正常登录。本轮恢复 Google 登录后停在验证器的 6 位验证码，需账号持有人直接完成。

4. 核对交易 ID、金额和 USD 与 Stripe 同一订单一致；刷新报告不应新增购买。

### 每日检查与停止

1. 打开本系列，右上角日期改“今天”或“昨天”，看费用、点击、转化次数、每次转化费用。
2. “列” → 修改列，加入转化价值、转化价值/费用。只用购买评估销售。
3. “洞察和报告” → “搜索字词”，将明显无关搜索选中 → “添加为否定关键字” → 本广告系列。
4. 确认报表只看本系列，避免共享账号其他站点混入。
5. 累计费用接近 US$30 先暂停复盘。无购买或净贡献不覆盖广告费时，不加预算；暂停后继续核对归因延迟产生的订单。
6. 暂停：“广告系列”列表 → 名称左侧状态图标 → “暂停” → 刷新确认。

`净贡献 = 实收 - 退款 - 支付手续费 - 税费及其他边际成本 - 广告费用`。ROAS 大于 1 也未必盈利。若付费点击上升、自然点击下降、总订单不增，应考虑广告替代自然流量。
